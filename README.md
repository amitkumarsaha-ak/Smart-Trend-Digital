## 🛠️ How to Run Locally

### Prerequisites
* Node.js v18+ (Node v24 tested)
* npm

### Development Mode (Concurrent Client & Server)
```bash
npm run dev
```
* Frontend Vite Live Server: `http://localhost:5173`
* Backend Express API Server: `http://localhost:5050`

Or run them individually:
```bash
# Run only frontend
npm run dev:client

# Run only backend
npm run dev:server
```

### Production Build & Launch
```bash
# 1. Build the React frontend
npm run build

# 2. Start the Express server (serves the built React app + API endpoints)
npm start
```
Visit: `http://localhost:5050`
